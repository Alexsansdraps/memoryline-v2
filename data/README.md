# Exports cliente

- `exports/` : exports **réels** fournis par la cliente (Shopify CSV/JSON, bibliothèque personnages/assets).
  **Gitignored** (données réelles + PII). Déposer les fichiers ici tels quels.
- `samples/` : échantillons **anonymisés** versionnés, pour développer/tester l import sans données réelles.

Voir §10 et §11 du [PLAN_DE_DEV.md](../PLAN_DE_DEV.md).
